--------------------------------------------------------------------
0. clamp() の読み方（可変の余白）
--------------------------------------------------------------------
多くのセクションは clamp(最小px, 可変, 最大px) を使い、画面幅で自動可変する。
  - 狭い画面 → 最小px / 中間 →「可変」(例10vw=画面幅の10%) / 広い画面 → 最大px
基準幅での確定値:
  clamp(80px, 10vw, 136px)  … 1400px幅→136px（10vw=140→上限136）／ 390px幅→80px（下限）
  clamp(96px, 12vw, 160px)  … 1400px幅→160px（上限）／ 390px幅→96px（下限）
  clamp(48px, 6vw, 80px)    … 1400px幅→80px（上限）／ 390px幅→48px（下限）
ヘッダー高さ変数: --header-h = 76px

--------------------------------------------------------------------
1. 全セクション共通のベース値（.section）
--------------------------------------------------------------------
.section { padding-block: clamp(80px, 10vw, 136px); }
  → 1400px幅: 上下 136px ／ 390px幅: 上下 80px（どちらも8の倍数）
  ※レスポンシブでも上書きなし。clampのvwで自動可変

--------------------------------------------------------------------
3. 8の倍数チェックの結論
--------------------------------------------------------------------
● ユーザー指定セクション（トップ各・SERVICE/WORKS/CAREERの導入と各項目・
  インタビュー各セクション＝すべて .section / svc-intro）は、
  1400px→136px・390px→80px で いずれも8の倍数 → 修正不要。
● 指定範囲外だったヘッダー高さ(76px)を含む上余白3箇所も、2026-08-17に8の倍数へ修正済み（P-023）:
  - 下層ページヒーロー .page-hero 上124→120px（=76+44）
  - インタビューFV     .itv-hero  上132→128px（=76+52）
  - 404               .coming-soon 上172→168px（=76+92）
  → これで全セクションの上下余白が8の倍数（またはsvc-intro下0）に揃った。

--------------------------------------------------------------------
4. ヒーロー系の上余白の8の倍数化（実施済み・P-023 / 2026-08-17）
--------------------------------------------------------------------
  header-h(76) は固定のため、追加値を調整して合計を8の倍数にした:
  - .page-hero  上124 → 120px（calc(76+44)）
  - .itv-hero   上132 → 128px（calc(76+52)）
  - .coming-soon上172 → 168px（calc(76+92)）
