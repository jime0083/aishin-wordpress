--------------------------------------------------------------------
0. 前提：clamp() の読み方（可変の余白）
--------------------------------------------------------------------
多くのセクションは可変値 clamp(最小px, 可変, 最大px) を使う。意味は次のとおり:
  - 画面が狭いとき … 最小px
  - 画面が中くらい … 「可変」の値（例 10vw = 画面幅の10%）に追従
  - 画面が広いとき … 最大px
例) clamp(80px, 10vw, 136px)
  - 画面幅 800px以下  → 80px（10vw=80px が下限80pxに達する）
  - 画面幅 800〜1360px → 画面幅×10%（例: 1000px幅なら100px）
  - 画面幅 1360px以上 → 136px（上限）

ヘッダー高さの変数: --header-h = 76px（下層ヒーローの上余白計算に使用）

--------------------------------------------------------------------
1. 全セクション共通のベース値
--------------------------------------------------------------------
.section { padding-block: clamp(80px, 10vw, 136px); }
  → 上下それぞれ「80px（狭い画面）〜136px（広い画面）」で可変（基準10vw）
  ※このベースはレスポンシブ（900px以下）でも上書きされず、clampのvwで自動調整される

3. 補足（余白の見え方について）
--------------------------------------------------------------------
- 隣り合うセクションの間の「見た目の空白」は、上のセクションの下padding ＋ 下のセクションの
  上padding が積み重なった合計になる。
  例) ABOUT(下136px) と WORKS(上136px) が隣接 → 最大で 136+136=272px の空きに見える
  （画面幅が狭いと 80+80=160px）。
- 背景が交互に色づくセクション（.section--tinted＝薄いベージュ背景）は、余白が同じでも
  背景色の切り替わりで区切りが分かりやすくなっている。
- svc-intro は下paddingを 0 にして、直後の SERVICE/WORKS/CAREER 本編セクションと
  余白を詰め、「導入→本編」を一続きに見せている。
