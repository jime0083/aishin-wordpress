--------------------------------------------------------------------
0. これは何か（ひとことで）
--------------------------------------------------------------------
各セクションの背景に、そのセクションを表す英単語（MISSION / ABOUT / WORKS など）を
「巨大・極薄・塗りつぶしなしの輪郭線だけ」で敷き、スクロールに合わせて左右にゆっくり
流す装飾です。本文の可読性を一切邪魔しないよう、下記3つの工夫がしてあります。
  1) 文字の中身は透明で「輪郭線（アウトライン）だけ」＋色をごく薄く
  2) z-index で本文より下（背面）に置く
  3) pointer-events:none / user-select:none でクリックや選択の邪魔をしない

--------------------------------------------------------------------
1. 仕組みの全体像（3つの部品）
--------------------------------------------------------------------
  ① HTML … セクションの中に <span> で英字を1つ置く（データ属性で流す向きを指定）
  ② CSS  … その <span> を「巨大・アウトラインのみ・極薄・背面・絶対配置」にする
  ③ JS   … GSAP の ScrollTrigger で、スクロール量に連動して横に平行移動させる

  使用ライブラリ: GSAP 3.x ＋ ScrollTrigger（スクロール連動アニメの定番）

--------------------------------------------------------------------
2. ① HTML（1行だけ）
--------------------------------------------------------------------
各セクションの一番上に、次の <span> を1つ置きます。

  <span class="giant-word giant-word--left" data-giant="left" aria-hidden="true">ABOUT</span>

  - class の `giant-word--left / --right` … 画面の左寄せ / 右寄せ
  - `data-giant="left"（or "right"）` … JSが「流す向き」を読むための目印
  - `aria-hidden="true"` … 装飾なので読み上げソフトからは隠す（アクセシビリティ配慮）
  - 中身のテキスト（ABOUT など）… セクション名の英単語

このプロジェクトでは PHP のテンプレートパーツにして、各セクションから
  get_template_part('template-parts/giant-word', null, ['text'=>'ABOUT','side'=>'left']);
のように「文字」と「左右」を渡して呼び出しています（giant-word.php）。
実際の使用例（テキスト, 向き）:
  MISSION(右) / ABOUT(左) / WORKS(左) / PEOPLE(右) / GROWTH(左) /
  CAREER(右) / SUPPORT(右) / INTERVIEW(右) / 各SERVICEやWORKSは左右交互 など

--------------------------------------------------------------------
3. ② CSS（見た目：巨大・アウトライン・極薄・背面）
--------------------------------------------------------------------
.giant-word {
  position: absolute;      /* セクション内で自由配置（親に position:relative が必要） */
  top: 6px;                /* セクション上端あたりに置く */
  z-index: 0;              /* 本文（z-index:1以上）より下に敷く＝背面 */
  font-family: 'Syne', sans-serif;  /* 英字が映えるフォント */
  font-weight: 800;        /* 極太 */
  font-size: clamp(80px, 17vw, 240px); /* 画面幅に応じて80〜240pxに伸縮（巨大） */
  line-height: 1;
  white-space: nowrap;     /* 改行させない（1行の巨大英字） */
  color: transparent;      /* ★中身を透明にして「塗り」を消す */
  -webkit-text-stroke: 1.5px rgba(255, 90, 31, 0.16); /* ★輪郭線だけ・極薄オレンジ */
  pointer-events: none;    /* クリック等を透過（本文操作を邪魔しない） */
  user-select: none;       /* 文字選択の対象にしない */
  will-change: transform;  /* 移動アニメを滑らかに（GPUヒント） */
}
.giant-word--right { right: -2%; }  /* 右寄せ（少し画面外にはみ出す） */
.giant-word--left  { left:  -2%; }  /* 左寄せ（少し画面外にはみ出す） */

  ★可読性を邪魔しない核心はこの2行:
    color: transparent;                         … 中身を消す
    -webkit-text-stroke: 1.5px rgba(色, 0.16);  … 輪郭だけ・透明度16%の極薄
  （※ -webkit-text-stroke は主要ブラウザで動作。塗りにしたい場合は color を付ける）

  親セクション側には `position: relative;` と `overflow: hidden;` を付けておくと、
  巨大英字がセクション外へはみ出しても他へ影響しません（このサイトの .section が該当）。

--------------------------------------------------------------------
4. ③ JavaScript（スクロール連動で横に流す）
--------------------------------------------------------------------
GSAP＋ScrollTrigger で、[data-giant] を持つ要素すべてを対象に、
セクションが画面を通過する間に横方向へ平行移動させます。

  gsap.utils.toArray('[data-giant]').forEach(function (el) {
    var dir = el.dataset.giant === 'left' ? 1 : -1;  // 左寄せは+、右寄せは−方向
    gsap.fromTo(
      el,
      { xPercent: 6 * dir },      // 開始位置（自身の幅の +6%（左）/ −6%（右））
      {
        xPercent: -10 * dir,      // 終了位置（自身の幅の −10%（左）/ +10%（右））
        ease: 'none',             // 等速（スクロールに素直に追従）
        scrollTrigger: {
          trigger: el.parentElement || el, // 親セクションを監視対象に
          start: 'top bottom',    // セクション上端が画面下端に来たら開始
          end: 'bottom top',      // セクション下端が画面上端に抜けたら終了
          scrub: 0.6,             // ★スクロール量に連動（0.6秒かけて滑らかに追従）
        },
      }
    );
  });

  ポイント:
  - `scrub: 0.6` が肝。true/数値にすると「再生」ではなく「スクロール位置に同期」して
    進んだり戻ったりする（スクロールを止めれば止まる）。0.6は追従の滑らかさ（慣性）。
  - xPercent は「自分の文字幅に対する％」。要素幅基準なので文字が長くても破綻しにくい。
  - dir で左右の流れる向きを反転（左寄せの文字と右寄せの文字が逆方向に流れる）。
  - trigger をセクション（親）にすることで「そのセクションが画面内にある間だけ」動く。

  前提: ページで gsap と ScrollTrigger を読み込み、`gsap.registerPlugin(ScrollTrigger)`
        を実行しておくこと。

--------------------------------------------------------------------
5. まとめ（最小レシピ）
--------------------------------------------------------------------
1) 各セクション（position:relative; overflow:hidden;）の先頭に
   <span class="giant-word giant-word--left" data-giant="left" aria-hidden="true">ABOUT</span>
2) .giant-word に「絶対配置・巨大・color:transparent＋text-stroke極薄・z-index:0・
   pointer-events:none」を指定
3) GSAP+ScrollTriggerで [data-giant] を xPercent 6→-10（向きは左右で反転）・scrub連動

6. 他サイトで同じ実装をしてほしいときの「指示の出し方」例
--------------------------------------------------------------------
そのままAI/開発者に渡せる指示文の例です（コピペ用）。必要に応じて色や単語を変えてください。

【指示例A（そのまま依頼）】
  「各セクションの背景に、そのセクション名の巨大な英字（例: ABOUT, WORKS）を装飾として
   敷いてください。要件は次の通り:
   ・文字は塗りつぶさず輪郭線だけ（CSSの color:transparent + -webkit-text-stroke）で、
     色はテーマのアクセント色を透明度15%前後にした極薄にする
   ・フォントは極太、サイズは画面幅に応じて clamp(80px, 17vw, 240px) 程度の巨大サイズ
   ・本文の可読性を邪魔しないよう z-index で背面（本文より下）に置き、
     pointer-events:none / user-select:none にする
   ・各セクションで左寄せ/右寄せを交互にし、少し画面外へはみ出す配置にする
   ・GSAPのScrollTriggerを使い、セクションが画面を通過する間に横方向へ平行移動させる
     （scrubでスクロール量に同期、左寄せと右寄せで流れる向きを反転、移動量は自身の幅の
     ±10%程度、等速ease:none）
   ・親セクションは position:relative; overflow:hidden; にする」

【指示例B（短く要点だけ）】
  「セクション背景に“極薄アウトラインの巨大英字”を敷き、GSAP ScrollTriggerのscrubで
   スクロール連動の横スクロール（パララックス）をかけて。本文の邪魔をしないよう背面・
   pointer-events:noneで。左右のセクションで流れる向きは逆に」

【伝えると精度が上がる補足情報】
  ・アクセント色（例: #ff5a1f）と、その透明度（例: 0.16）
  ・文字サイズの範囲（最小/最大）
  ・移動量（±何％）と scrub の値（追従の滑らかさ）
  ・使うフォント（英字が映える太めのディスプレイフォント）

7. 調整・カスタマイズの早見表
--------------------------------------------------------------------
  | 変えたいこと            | いじる場所                          | 例 |
  |-------------------------|-------------------------------------|----|
  | 文字の薄さ・色          | CSS -webkit-text-stroke の rgba     | 透明度0.16→0.10でさらに薄く |
  | 塗りつぶしにする        | CSS color を色に変更（strokeは任意）| color: rgba(色,0.1) |
  | 文字の大きさ            | CSS font-size の clamp 値           | clamp(60px,14vw,200px) |
  | 流れる量（動きの強さ）  | JS の xPercent（6 と -10）          | 3→-6 で控えめ |
  | 追従の滑らかさ/慣性     | JS の scrub 値                      | 0.6→1.2 でよりゆったり |
  | 流れる向き              | JS の dir 計算 / HTMLの data-giant  | left/right を入替 |
  | 縦位置                  | CSS top                             | top: 6px → 20px |

  ※本プロジェクトはデザイン確定済みのため、ここの値は変更しないこと（応用は別サイトで）。

====================================================================
用語ミニ辞典
====================================================================
  アウトライン文字 … 中身を塗らず輪郭線だけで見せる文字（color:transparent+text-stroke）
  z-index ………… 重なり順。小さいほど奥（背面）。背景文字は0、本文は1以上
  pointer-events:none … その要素がマウス操作を受けない（下の本文を操作できる）
  GSAP …………… 高機能アニメーションライブラリ
  ScrollTrigger … GSAPのプラグイン。スクロール位置とアニメを結びつける
  scrub ………… スクロール量にアニメを“同期”させる設定（再生ではなく連動）
  xPercent ……… 要素自身の幅を基準にした横移動量（%）。文字長に強い
  パララックス … 要素ごとに速度差をつけてスクロールさせ、奥行きを感じさせる演出
